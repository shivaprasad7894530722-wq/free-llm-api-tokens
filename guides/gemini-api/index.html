Gemini API free tier — compatibility, base URL and notes

Google’s Gemini API is listed as an official, OpenAI-compatible service with a free tier on selected models. This page only repeats what our tracker and the official docs publish.

Last updated 12 Nov 2026. The provider figures on this page follow the tracker snapshot of 13 Nov 2026, 08:57 IST.

What is the Gemini API on this tracker?

The row is named Gemini API (Google AI Studio) and is listed as an official provider. OpenAI compatibility is Yes. The recorded free allowance is “Free tier on selected Gemini models”. Tokens per day are Not published — Google does not give us a single daily token number to store, so we do not invent one. Limits are recorded as “Per-model RPM/RPD on Google's rate-limit page”. A card is recorded as No. Relay warning: no.

Our notes say: Free-tier prompts may be used to improve Google products. That is a policy point, not a performance claim, and you should read the official terms for the current wording. How do I call Gemini with an OpenAI-compatible client?

Our list records this base URL: https://generativelanguage.googleapis.com/v1beta/openai/. Copy it exactly, including the path suffix. Create a key in Google AI Studio (or the official console the docs currently describe), store it in an environment variable, and pass it to the official OpenAI SDK. Copy the model id from Google’s official Gemini documentation. We will not invent a model name here.

Python

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["API_KEY"],
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/",
)

resp = client.chat.completions.create(
    model="MODEL_ID",  # copy the model id from the provider's docs
    messages=[{"role": "user", "content": "Hello"}],
)
print(resp.choices[0].message.content)

JavaScript

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.API_KEY,
  baseURL: "https://generativelanguage.googleapis.com/v1beta/openai/",
});

const resp = await client.chat.completions.create({
  model: "MODEL_ID", // copy the model id from the provider's docs
  messages: [{ role: "user", content: "Hello" }],
});
console.log(resp.choices[0].message.content);

curl

curl https://generativelanguage.googleapis.com/v1beta/openai/chat/completions \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"MODEL_ID","messages":[{"role":"user","content":"Hello"}]}'

The MODEL_ID string is not guessed here. Copy it from the provider’s dashboard or official model list, because catalogues change.

If the official docs also describe a native Gemini SDK or a different endpoint, that does not contradict compatibility. It is another supported interface. This page focuses on the compatible base URL we recorded, because that is what most people need to switch an existing OpenAI client.

Why are tokens per day “Not published”?

Because the public sources we used did not give a single tokens-per-day number for the free tier as a whole. The limits field points you to Google’s rate-limit page, where caps may be expressed per model as RPM or RPD. We leave the numeric tokens-per-day field empty rather than averaging or guessing. See Rate limits explained for how to read those units, and always open the official rate-limit page on the day you use the API.

“Selected models” in the allowance means the free tier does not automatically include every Gemini model. Which models are selected can change. Official docs are the source for the current set.

What does the free-tier prompt note mean in practice?

Our notes record that free-tier prompts may be used to improve Google products. If that does not fit your data — private source code, customer text, or anything you cannot send to a product-improvement pipeline — do not put that data in the free tier. Check whether a paid official tier has a different policy, or use a different official provider, or run a model locally. This site cannot change Google’s policy and will not hide the note.

The same caution applies to any official free tier with a similar disclosure. “Official” is about who operates the API, not about training or retention. See Official providers vs gateways.

Is a credit card required?

In our data, card required is No. Confirm during signup, because official flows change. If you are choosing a first API and want to avoid a card, use the tracker filter and then read the official page, as described in A free LLM API for beginners.

How should I handle keys for Gemini?

Treat the key as a secret, like any other provider key. Keep it out of git, browser demos and chat logs. If you use the OpenAI-compatible URL in a coding assistant, issue a dedicated key so you can revoke it without affecting other projects. See How to keep API keys safe.

Do not send your Gemini key to a third-party “relay” so it can call Google on your behalf unless you fully trust that operator. A leaked official key is more serious than a key that only exists on a throwaway gateway account.

How does this compare with other official rows?

Gemini is useful to compare with Groq and Cloudflare Workers AI because all three are official and recorded as OpenAI compatible, and all three currently list no card in our file, but they publish different kinds of allowance: a daily token and request cap (Groq), a Neuron cap (Cloudflare), and a selected-model free tier with per-model official rate limits (Gemini). None of those units should be converted into each other on this site.
