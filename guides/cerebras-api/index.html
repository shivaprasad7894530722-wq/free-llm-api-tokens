Cerebras API trial allowance and compatible base URL

Cerebras is an official, OpenAI-compatible API in our list. The recorded free allowance is a high daily token cap during a short, card-required trial — not an ongoing no-card tier.

Last updated 12 Nov 2026. The provider figures on this page follow the tracker snapshot of 12 Nov 2026, 08:59 IST.

What is Cerebras on this tracker?

Cerebras is listed as an official provider with OpenAI compatibility Yes. The recorded free allowance is “1,000,000 tokens/day during $5 30-day trial”. Tokens per day are 1,000,000. Limits are Not published. Card required is Yes. Relay warning: no. Our notes say: Trial only, card required, 30 days.

How should I read a trial cap that looks large?

A daily token number of 1,000,000 can look high next to ongoing free tiers in the current snapshot. The same row also says the figure applies during a $5 30-day trial and that a card is required. If you sort only by tokens per day, you miss the time limit and the card. This is why our tables keep the written allowance and the card column, and why this guide exists beside the table.

When the trial window in the official terms ends, do not assume the same daily cap continues. We will mark the row when we see a public change; until then, the official plans page is the authority.

Limits in our file are Not published. That means we did not record a separate public RPM or RPD figure, not that requests are unlimited. See Rate limits explained.

How do I call the published endpoint?

The base URL we record is https://api.cerebras.ai/v1. Use the official OpenAI SDK, a key from the Cerebras account you create, and a model id from Cerebras’s official docs. Do not invent a model name here.

Python

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["API_KEY"],
    base_url="https://api.cerebras.ai/v1",
)

resp = client.chat.completions.create(
    model="MODEL_ID",  # copy the model id from the provider's docs
    messages=[{"role": "user", "content": "Hello"}],
)
print(resp.choices[0].message.content)

JavaScript

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.API_KEY,
  baseURL: "https://api.cerebras.ai/v1",
});

const resp = await client.chat.completions.create({
  model: "MODEL_ID", // copy the model id from the provider's docs
  messages: [{ role: "user", content: "Hello" }],
});
console.log(resp.choices[0].message.content);

curl

curl https://api.cerebras.ai/v1/chat/completions \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"MODEL_ID","messages":[{"role":"user","content":"Hello"}]}'

The MODEL_ID string is not guessed here. Copy it from the provider’s dashboard or official model list, because catalogues change.

If official docs require extra signup steps — a card, a trial opt-in, or a console flag — complete those first. A valid-looking key can still be rejected if the trial is not active.

Why is a card required, and what should I watch for?

Our data records card required as Yes, and the notes repeat that the trial is 30 days with a card. A card on file can make it easier to continue onto a paid plan when a trial ends. Watch official emails and the billing dashboard so you are not surprised by a charge after the window described in the official terms. This site is not affiliated with Cerebras and cannot cancel a trial for you.

If you want an official compatible API whose card field is currently “No” in our list, compare rows in the snapshot tables rather than assuming every official provider has the same payment rule.

Is Cerebras a relay?

No. It is classified as official, with no relay warning. You still need to read Cerebras’s terms for data use. Prefer official providers over flagged relays for private prompts, as explained in Relay and gateway risks. Keep the trial key in the environment and revoke it if it leaks; see How to keep API keys safe.

How might I use the trial carefully?

Decide in advance whether a 30-day official trial fits the work. Put a reminder on the end date that the official terms describe. Use a dedicated key. Start with a small request, then — if you connect a coding assistant — set a local request cap so the daily token figure is not spent in an unattended loop.

If you later move to another official compatible API, change the environment’s key, base URL and model id. Application code can stay the same if you only used features that both APIs support.

How do I verify this row?

Compare the fact box with Cerebras’s official plans and docs. If the trial wording, the daily token figure, the card rule or the base URL has changed, send the official link. We will not keep a high tokens-per-day figure in the “best of” table as if it were an unlimited ongoing plan.

What should I log during the trial, and what should I never log?

Log the model id, the HTTP status and a timestamp so you can see how fast you are approaching the published daily token figure. Do not log the API key, the full request payload if it contains secrets, or card details. If you take screenshots for a teammate, crop the key.

If several people share the trial, they are also sharing the published cap. Agree who may run an agent overnight. A single unattended loop is enough to spend a daily token allowance that looked large in a table.

What happens in my own planning when the 30 days end?

Read the official terms for what the account becomes after the trial: paid, disabled, or a smaller plan. This site will not invent that outcome. Set a reminder from the official start date, keep a second official provider ready if you still need a free compatible endpoint, and revoke keys you no longer use. Compare ongoing official options in the current snapshot instead of assuming a trial cap will be extended informally.
