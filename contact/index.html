Contact

The best way to reach the maintainer is email. This site does not collect secrets through a form.

Last updated 12 Nov 2026.

How can I contact you?

Email shivaprasad2515@mail.grokbot.com. That is the only contact method this site publishes.

Please use it for:

  • A correction to a provider entry (include a link to the official page)
  • A question about how the tracker works
  • A privacy, data or takedown request
  • A problem with the website itself

What should I not send?

Do not send API keys, passwords, access tokens, backup codes or personal documents. We do not need them to correct a public figure, and you should treat any key that has been emailed as compromised. See How to keep API keys safe.

This page does not include a contact form. A form would be a tempting place to paste a key, and we will not collect that kind of data here.

How fast will I get a reply?

There is no published service-level agreement. Weekday messages about an incorrect public figure are the priority, because the list is also reviewed on weekdays.

For provider outages, billing or account access, write to the provider. This site does not operate any of the APIs in the list and cannot reset a key or restore a quota.
